# Pixel Bible generator (backup)
- `g5/` long-form 16:9 engine: `python3 build5.py <script> nar|drama tts|preview|render|mix|concat [part/total]`
  scripts: `genesis.py` (Part 1), `abraham.py` (Part 2). Characters: `cast5.py`, `abr_cast.py`. Sounds: `sfx.py`.
- `px/` pixel character sprites (chars2.py, eden_sprites.py). `voices.py` voice map. `gen4.py` Shorts generator.
- TTS model (not stored here): Kokoro `kokoro-v1.0.onnx` + `voices-v1.0.bin` in `tts/`.
